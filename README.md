# Park Session

Jeu de ski et snowboard freestyle en 3D, dans le navigateur.

- Ordinateur : `index.html`
- Téléphone : `mobile.html` (les téléphones y sont redirigés automatiquement ; ajouter `?pc` à l'adresse pour forcer la version ordinateur)

Moteur 3D : [three.js](https://threejs.org) (licence MIT), inclus dans le dépôt.
